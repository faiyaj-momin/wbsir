**SIR Electoral Appeal Generator (2026)**
A smart legal document generator for handling Electoral Roll **Special Intensive Revision (SIR) 2026** cases.

This project automatically generates structured, tribunal-ready appeal applications for issues like wrong linkage, age gap discrepancies, name mismatches, and duplicate entries. It includes a rule-based condition engine that dynamically merges multiple cases into a single coherent legal document.

### ✨ Features

* Dynamic case-based paragraph injection engine
* Supports father / mother / parent-aware logic
* Intelligent age-gap validation (under 15 / over 50, valid vs invalid)
* Auto sibling & position reasoning (e.g., 11th child logic)
* Clean legal formatting with sections, numbering, and verification
* PDF generation using html2canvas + jsPDF
* Modern typography using Google Inter font
* Ready for Vite + React integration

### 🚀 Use Cases

* Electoral roll correction appeals
* BLO notice response drafting
* Legal affidavit-style applications
